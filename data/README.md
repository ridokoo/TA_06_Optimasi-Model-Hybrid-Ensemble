# Data

Dataset tidak disertakan di repository.

1. Unduh **Diabetes Health Indicators Dataset** (A. Teboul) dari Kaggle:
   https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset
2. Letakkan file `diabetes_012_health_indicators_BRFSS2015.csv` di folder ini.
3. Jalankan pipeline dari root repository:
   `python ml/pipeline_prediabetes.py --data data/diabetes_012_health_indicators_BRFSS2015.csv --out ml/hasil`
